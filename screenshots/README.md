# Screenshots

**Scope:** Images shown in the Community Themes store and this repo’s README.  
**When to use:** Before first community submission, and whenever the visual design changes materially.

## Required files

| File | Mode | Notes |
|------|------|-------|
| `dark.png` | Dark | 16:9, recommended **512×288** |
| `light.png` | Light | Same dimensions |

## Checklist

- [ ] Capture a representative note (headings + code block) in Dark mode
- [ ] Capture the same note in Light mode
- [ ] Crop/resize to 16:9 (512×288 preferred for fast loading)
- [ ] Save as `dark.png` and `light.png` in this folder
- [ ] Confirm README table renders both images

PNG files are not committed as placeholders — add real screenshots before submitting.
